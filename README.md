# AEGIS - Mobile assessment app (scaffold)

This repository contains an Expo React Native scaffold and a small Express backend stub for the AEGIS assessment app.

What I pushed in the aegis/scaffold branch:
- frontend/ (Expo app)
- backend/ (Node/Express stubs for stamping, PDF and crime stats)

Quick start (frontend)
1. Install dependencies: cd frontend && yarn
2. Start Expo: yarn start

Quick start (backend)
1. cd backend && yarn
2. Start server: yarn start

Notes
- Replace assets/logo.png with your Servest logo (I placed a placeholder file and instructions).
- STT, crime-data, and email sending are stubbed and pluggable. See backend/README.md for where to place API keys.
